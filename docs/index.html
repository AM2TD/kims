How it works

Sample33 numbers per sample: a start-state offset and 4 cosine terms per IMU channel
Roll outevery sample is an IMU trajectory, so every hypothesis is kinematically feasible
Weight and carryUWB likelihood weights, tempered when they collapse, and the window moves on by its moments

Why sampling

The same window objective solved by Levenberg–Marquardt is never better than KIMS by more than 1 cm, and worse on 14 of 104 flights. All 14 pass close to the anchor plane, where the posterior splits in two and a mode follows one branch.

Speed

Desktop RTX 5070 Ti: 4–9 ms mean per UWB epoch at N = 8192.
Onboard Jetson Orin NX: 6–10 ms median at N = 1280–2560, inside the 10 ms epoch of IULUI, with the RMSE of N = 8192.

Quick start

# build (CUDA GPU, no ROS)
cmake -S . -B build -DKIMS_NO_ROS=ON && cmake --build build -j8

# one flight, score, plot
python3 scripts/run.py kims iului SquareTurn
python3 scripts/evaluate.py
python3 scripts/plot.py iului SquareTurn

# all 104 flights (or: docker/build.sh && docker/run.sh)
scripts/reproduce.sh

# online, ROS Noetic: catkin_make, then a shipped bag in real time
roslaunch kims kims_online.launch seq:=SquareTurn rviz:=true
